# Holberton School Web React - TypeScript

This repository contains tasks and projects for the **TypeScript** curriculum in the Web React module.

## Projects Covered
- `task_0`: Creating an interface for a Student and rendering a table using Vanilla JavaScript.
- `task_1`: Building `Teacher` & `Directors` interfaces, `printTeacher` function, and `StudentClass`.
- `task_2`: Advanced TypeScript types (Union Types, Type Guards, String Literal Types).
